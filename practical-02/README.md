# Практична робота №2

## Інтеграція хмарних застосунків за допомогою SAP Integration Suite

### Мета роботи

Ознайомитися з основними можливостями **SAP Integration Suite** для інтеграції хмарних застосунків, отримати практичні навички створення, налаштування, тестування та розгортання **Integration Flow (iFlow)**, а також навчитися використовувати маршрутизацію повідомлень, перетворення форматів даних і автоматичний запуск інтеграційних сценаріїв.

У межах практичної роботи необхідно:

1. активувати та налаштувати **SAP Integration Suite** у SAP BTP;
2. створити та розгорнути базовий **Integration Flow**;
3. створити Integration Flow для надсилання повідомлень у **SAP Build Work Zone**;
4. реалізувати формування відповіді у форматах **JSON** та **XML** залежно від вхідних даних;
5. налаштувати автоматичний запуск Integration Flow за розкладом.

---

## Оцінювання практичної роботи

Максимальна кількість балів за практичну роботу — **20 балів**.

1. Створення та розгортання базового **Integration Flow** — **5 балів**.
2. Створення Integration Flow для надсилання повідомлень у **SAP Build Work Zone** — **5 балів**.
3. Реалізація формування відповіді у форматах **JSON/XML** залежно від параметра вхідного повідомлення — **5 балів**.
4. Створення та налаштування Integration Flow з автоматичним запуском за розкладом — **5 балів**.

> Налаштування та активація **SAP Integration Suite** є підготовчим етапом практичної роботи й окремо не оцінюється.

**Разом: 20 балів.**

# 1. Загальна схема виконання практичної роботи

Практична робота складається з чотирьох основних частин.

## Частина 1. Створення базового Integration Flow

У першій частині необхідно ознайомитися з хмарним сервісом **SAP Integration Suite**, активувати його в SAP BTP Trial та створити базовий **Integration Flow** відповідно до інструкцій SAP.

У результаті має бути створений, розгорнутий та протестований Integration Flow.

Для виконання цієї частини використовуйте інструкції:

1. **Активація SAP Integration Suite:**  
   https://developers.sap.com/tutorials/cp-starter-isuite-onboard-subscribe.html

2. **Створення та розгортання Integration Flow:**  
   https://developers.sap.com/tutorials/cp-starter-integration-cpi-design-iflow.html

## Частина 2. Надсилання повідомлень у SAP Build Work Zone

У другій частині необхідно створити Integration Flow для надсилання **push-повідомлень у SAP Build Work Zone**.

Для виконання цієї частини використовуйте інструкцію:

https://github.com/yuray76/btp-helloworld-app/blob/main/kpiCPI/README.md

У результаті після запуску Integration Flow повідомлення повинно відображатися в **SAP Build Work Zone**.

## Частина 3. Формування JSON/XML

У третій частині необхідно модифікувати Integration Flow, створений у **частині 1**, та додати до вхідного повідомлення параметр `format`.

Залежно від значення параметра Integration Flow повинен повертати результат у відповідному форматі:

- `format = json` — **JSON**;
- будь-яке інше значення — **XML**.

Результат повинен повертатися у форматованому (**Pretty**) вигляді.

## Частина 4. Автоматичний запуск Integration Flow

У четвертій частині необхідно створити копію Integration Flow, розробленого у **частині 2**, та модифікувати її таким чином, щоб надсилання повідомлення в **SAP Build Work Zone** виконувалося автоматично за розкладом.

Наприклад, можна налаштувати автоматичне надсилання повідомлення **щодня о 9:00**.

У результаті повідомлення повинно надсилатися в SAP Build Work Zone автоматично у визначений час без ручного запуску Integration Flow.
