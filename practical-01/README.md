# Практична робота №1

## Створення та розгортання SAP Fiori застосунків у SAP Business Technology Platform

## 1. Мета роботи

Метою практичної роботи є ознайомлення з основними етапами створення, розгортання та публікації хмарних застосунків у **SAP Business Technology Platform (SAP BTP)**, а також набуття практичних навичок роботи з інструментами та сервісами платформи.

У межах практичної роботи необхідно:

- ознайомитися з можливостями **SAP BTP Trial** та основними компонентами платформи;
- налаштувати середовище для розробки HTML5-застосунків;
- створити та запустити застосунок **Hello World** у **SAP Business Application Studio**;
- виконати розгортання застосунку в середовищі **Cloud Foundry**;
- ознайомитися з використанням **Git** та **GitHub** для керування вихідним кодом;
- налаштувати процес **CI/CD** для автоматизації збирання та розгортання застосунку;
- опублікувати застосунок у **SAP Build Work Zone**;
- створити **SAP Fiori Elements** застосунок на основі публічного OData-сервісу **Northwind**;
- налаштувати **Destination** у SAP BTP для доступу до зовнішнього OData-сервісу;
- дослідити використання **OData-анотацій** для формування інтерфейсу SAP Fiori Elements застосунку;
- реалізувати відображення списку постачальників, сторінки окремого постачальника та пов'язаних із ним товарів;
- виконати build та deploy створеного SAP Fiori Elements застосунку;
- додати створений застосунок до **SAP Build Work Zone**.

У результаті виконання практичної роботи студент повинен розуміти загальний життєвий цикл хмарного застосунку в SAP BTP — від створення проєкту та роботи з вихідним кодом до його автоматизованого розгортання та публікації для кінцевих користувачів.
