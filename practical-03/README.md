
# Практична робота №3

## Створення мультитенантного SaaS-застосунку в SAP BTP

### Мета роботи

Ознайомитися з принципами побудови мультитенантних SaaS-застосунків у **SAP Business Technology Platform (SAP BTP)**, навчитися налаштовувати субакаунти Provider і Consumer, перетворювати SAPUI5-застосунок на SaaS, керувати підписками та забезпечувати доступ до застосунку через **SAP Build Work Zone, standard edition**.

### Оцінювання практичної роботи

Максимальна оцінка — **20 балів**.

| Завдання | Бали |
|---|---:|
| Перетворення Hello World на SaaS-застосунок та розгортання в Provider | 10 |
| Створення Consumer-субакаунта і оформлення підписки | 4 |
| Створення плитки у SAP Build Work Zone для доступу до SaaS-застосунку з Consumer-субакаунту  | 6 |
| **Разом** | **20** |

---

# 1. Загальна схема виконання практичної роботи

Практична робота складається з трьох основних частин.

## Частина 1. Перетворення Hello World на SaaS-застосунок

Необхідно перетворити застосунок **Hello World**, створений у практичній роботі №1, на мультитенантний SaaS-застосунок та розгорнути його в субакаунті **Provider**.

У результаті SaaS-застосунок повинен бути успішно розгорнутий у Provider та доступний для оформлення підписок іншими субакаунтами.

## Частина 2. Створення Consumer-субакаунта

Необхідно створити додатковий субакаунт SAP BTP, наприклад:

- **Consumer 1**

Для цього субакаунта необхідно оформити підписку на SaaS-застосунок **Hello World**, розгорнутий у Provider.

У результаті Consumer-субакаунт повинен мати активну підписку на SaaS-застосунок.

## Частина 3. Налаштування доступу через SAP Build Work Zone

Необхідно створити плитку в **SAP Build Work Zone, standard edition** в Consumer-субакаунті, яка забезпечуватиме доступ до SaaS-застосунку, фізично розгорнутому в субакаунті провайдера.

У результаті користувач повинен мати можливість запускати SaaS-застосунок через плитку.
